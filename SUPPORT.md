## Bugs and content issues

Open an issue at <https://github.com/somphol/vu_project_ideas/issues> with:

- the brief id or page URL;
- browser, version and viewport;
- what you did, what happened and what you expected;
- a screenshot if it is visual.

For a broken external link, include the URL and the HTTP status you see. Do not paste credentials,
tokens or personal data.

## Feature requests

Open an issue describing the student problem first, then the feature. The roadmap is deliberately
short; see [`docs/ROADMAP.md`](docs/ROADMAP.md) for non-goals.

## Security

Do not use a public issue. See [`SECURITY.md`](SECURITY.md).

## Conduct

See [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).

## What this project cannot help with

- Debugging the 52 unbuilt briefs or the two linked demos;
- recovering a lost shortlist (it is local only);
- hosting a private copy (fork it and use your own Pages);
- reviewing a student's implementation.

## Response expectations

This is a volunteer project. Issues are read when time allows; there is no SLA. A clear, reproducible
report is far more likely to be acted on than a one-line “it doesn't work”.
