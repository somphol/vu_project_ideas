TASK: Build a complete, production-ready, interactive educational web application named "Khan Trig Companion: Unit 4 Equations & Identities Studio" using vanilla HTML5, CSS3, ES6 JavaScript, and HTML5 Canvas.

======================================================================
PROJECT BACKGROUND & PEDIGREE:
======================================================================
This application is part of an open-source digital math booklet series
modeled strictly after the Khan Academy Trigonometry curriculum
(Unit 4: Trigonometric Equations & Identities). Its purpose is to help
students master inverse trigonometric functions, Pythagorean and reciprocal
identities, algebraic factorization of trig expressions, and solving
multi-solution equations over restricted or infinite intervals. It runs
entirely client-side with zero external frameworks and is optimized
for GitHub Pages deployment.

======================================================================
1. MODULE ARCHITECTURE (3 CORE INTERACTIVE PLAYGROUNDS)
======================================================================

Provide a top navigation tab bar allowing seamless switching
between 3 distinct learning modules:

----------------------------------------------------------------------
MODULE 1: INVERSE TRIGONOMETRIC FUNCTIONS & RESTRICTED DOMAINS
----------------------------------------------------------------------
- Pedagogical Goal: Demystify why arcsin, arccos, and arctan require
  strict domain restrictions to remain valid functions (one-to-one mapping).
- Canvas Components:
  - Interactive Graphing Canvas showing standard sine/cosine curves
    alongside their restricted inverse counterparts.
  - Domain / Range Sliders and point-dragging handles to show how
    restricting the input domain yields a single valid output angle θ.
  - Instant warning/success badges when user inputs fall inside or
    outside principal value branches.

----------------------------------------------------------------------
MODULE 2: PYTHAGOREAN IDENTITIES & ALGEBRAIC SIMPLIFICATION LAB
----------------------------------------------------------------------
- Pedagogical Goal: Teach sin²(θ) + cos²(θ) = 1, 1 + tan²(θ) = sec²(θ),
  and 1 + cot²(θ) = csc²(θ) through visual area models and step-by-step
  substitution checks.
- Interactive Controls:
  - Expression Builder / Selector: Choose from various complex trigonometric
    expressions (e.g., sec²(θ) - tan²(θ) or sin³(θ) + sin(θ)cos²(θ)).
  - Interactive Substitution Steps: Students click drop-down choices or
    substitution buttons to simplify expressions step-by-step, receiving
    immediate visual feedback if an algebraic step is invalid.

----------------------------------------------------------------------
MODULE 3: KHAN PRACTICE SANDBOX & EQUATION SOLVER
----------------------------------------------------------------------
- Pedagogical Goal: Solve trigonometric equations yielding multiple solutions
  (e.g., 2 sin(θ) - 1 = 0 on [0, 2π)).
- Problem Generator Modes:
  1. "Basic Trig Equations" (finding all angles satisfying a ratio condition).
  2. "Quadratic-Form Trig Equations" (factoring expressions like 2cos²(θ) - cos(θ) - 1 = 0).
  3. "Identity Verification Proofs".
- Interactive Features:
  - Input field for student answer with "Check Answer" button.
  - "💡 Show Step-by-Step Visual Solution" button: Animates the
    unit circle intersection points corresponding to all valid solutions.
  - Score Streak Counter & Mastery Badge System.

======================================================================
