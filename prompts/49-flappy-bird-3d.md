Build a complete, polished 3D Flappy Bird game in a single self-contained HTML file using HTML5, CSS3, vanilla JavaScript, and Three.js (imported via CDN).

Requirements:

3D Scene & Perspective:

Camera View: Position the camera behind a cute 3D bird model (or glowing sphere with wings), looking forward down an endless 3D flying tunnel/corridor.

Lighting & Environment: Add a vibrant sky gradient background, moving 3D cloud clusters, directional sunlight, and ambient lighting with shadow effects.

Game Mechanics & Physics:

Flight Physics: Pressing Spacebar or tapping the screen applies an upward velocity pulse (flap) to the bird, while constant gravity pulls it downward over time.

Endless 3D Pipes: Dynamically spawn pairs of textured green 3D cylinder pipes (top and bottom with a pass-through gap) moving toward the player along the Z-axis.

Bounding Box Collisions: Accurately detect collisions between the bird and pipe geometry or the ground floor.

UI / HUD & Arcade Audio:

Score HUD: Display a large retro arcade score counter at the top of the screen incrementing as the bird passes through each 3D pipe opening.

Synthesized Audio: Use the browser's native Web Audio API to create synthesized retro sound effects for flapping wings, scoring points, and hitting a pipe (crash).

Game Over Loop: Show a clean 'Game Over' overlay card with current score, high score saved to localStorage, and a 'Tap / Press Space to Restart' button.
