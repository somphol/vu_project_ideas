Build a complete, production-ready, beautiful multi-file ESL Pronunciation Coach web application. Please output the code separated into three distinct code blocks (index.html, style.css, and script.js) so it can be hosted directly on GitHub Pages.
Project Requirements & Specifications:
Modular Architecture:
index.html: Clean semantic markup containing the main application container, top navigation tabs, the active interactive practice box, and the word grid containers.
style.css: Modern styling using a soft, accessible color palette (indigo/slate accents, smooth hover transitions, card shadows, responsive CSS grid layouts, and active tab states).
script.js: Clean vanilla JavaScript handling word data structures, tab switching, speech synthesis audio playback, and speech recognition.
Categorized Word Lists (20 Words per Category):
The JavaScript file must manage four distinct categories with exactly 20 words each displayed as clickable grid cards:
- Rhymes: Cat, Hat, Bat, Mat, Rat, Day, Say, Play, Ray, Way, Light, Night, Bright, Sight, Flight, Cold, Hold, Bold, Gold, Told
- Starting Consonants & Blends: Blue, Chair, Fast, Green, House, Jump, Kite, Light, Mouse, Nest, Play, Quick, Read, Smile, Train, Voice, Water, Yellow, Zebra, Sheep
- Vowel Sounds: Cat, Cake, Bed, Bee, Pig, Bike, Pot, Bone, Cup, Tube, Map, Rain, Net, Tree, Sit, Light, Hot, Boat, Bus, Moon
- Ending Sounds & Blends: Bank, Fast, Hand, Milk, Jump, Desk, Camp, Tent, Bulb, Wolf, Nest, Risk, Pond, Gift, Belt, Lamp, Sand, Task, Pink, Salt
Browser Native Text-to-Speech (TTS):
Use the native browser SpeechSynthesisUtterance API.
When a user clicks any word card or the '🔊 Listen' button, the browser speaks the word out loud at a slightly slower rate (rate = 0.8) optimized for ESL learners.
Browser Native Speech-to-Text (STT) Pronunciation Check:
Use the browser's native webkitSpeechRecognition API when the user clicks '🎤 Test Pronunciation'.
Listen to the student's microphone input, compare what they said to the target word (case-insensitive and trimmed), and provide instant visual feedback (Green checkmark for correct matches, Red cross with what was heard if incorrect).
Please present the code clearly in separate code blocks labeled for index.html, style.css, and script.js.
