The method

From brief to shipped project

Every brief is a complete specification — not a one-line idea. The prefix asks the agent for the same release discipline every time.

  1. 01

    Pick a brief

    Filter by track or stack, skim the tagline, then open the full prompt. Shortlist the ones you want to build later.

  2. 02

    Copy the prompt

    One click gives you the current request prefix plus the original task body. Nothing is paraphrased or truncated.

  3. 03

    Build it for real

    Paste it into OpenCode, Claude Code, Cursor or your agent of choice. The prefix asks for docs, a state file, verification and a skill.

The standard request

One prefix. Every brief.

This is the latest version of the request wrapper. It is automatically placed above every prompt in the library. Replace {{TITLE}} with the project name.

Browse Markdown files

Why it exists: it makes the agent document the build for the next agent, capture time and tokens, publish to GitHub, and turn the result into a reusable skill.


      

    


    

      

        
Provenance

        
Built in the open, with the receipt.

        
This library was assembled in a single OpenCode session with DeepSeek V4.1 Flash. The original prompt list was recovered from the session database, parsed into 54 unique briefs, reviewed for duplicates, and published as a static site.

        
No accounts, analytics, cookies or backend. Favorites and theme live in your browser only. The full build record — elapsed time, token counters, file counts and verification — is in state.json.
